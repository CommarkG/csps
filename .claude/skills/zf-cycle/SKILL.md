# /zf-cycle — ZF Evidence Block Generator

## When to invoke

- Before any DONE/COMPLETE/SEALED claim (required per B_PRE_CLOSE_VERIFICATION)
- When compiling a FROM SONNET report to Opus
- At the end of a logical work unit (before handoff or session close)
- When /step-accept calls for ZF evidence

## Required inputs (provide as args or context)

1. What was examined (the work unit, files modified, claims made)
2. Specific files that were checked (must be real paths — validator rejects generic descriptions)

## Output format (MUST match exactly for validate-zf-cycle-format.mjs to accept)

```
ZF Cycle 1: <what was examined> — sources: <file1>, <file2>, <file3>. <finding or "0 new findings">

ZF Cycle 2: Re-checked <specific-file-1> (<what was confirmed>), <specific-file-2> (<what was confirmed>). 0 new findings.

Status: ZF ACHIEVED.
```

## Rules

- Cycle 1: name the WORK and the SOURCE FILES. Generic "I reviewed X areas" = nominal = validator BLOCKS.
- Cycle 2: name SPECIFIC FILES re-examined (not the same descriptions as Cycle 1 — must show re-examination).
- Both cycles must contain actual file paths, NOT descriptions. Format: `tools/data/file.yaml`, `docs/plan/protos/PROTO-X.md`.
- "ZF ACHIEVED." (with period) is the termination marker — validator looks for this exact string.
- For /verify-quick evidence: include `tools/verify-last-run.md (exit_code=0)` as one of the sources.

## Example (correct)

```
ZF Cycle 1: ITEM 1 K=4 gap fix — sources: tools/data/gap-recurrence-register.yaml (gap_DONE_CLAIM status=fix_committed, SHA=0fb5173), tools/tests/behavioral/done-claim-validator-gate-test.sh (11/11 tests PASS), tools/verify-last-run.md (exit_code=0 this turn).

ZF Cycle 2: Re-checked tools/data/gap-recurrence-register.yaml (structural_fix_committed SHA confirmed), .claude/hooks/pre-commit-claim-validator-gate.sh (file present and executable), .claude/settings.json (PreToolUse hook registered). 0 new findings.

Status: ZF ACHIEVED.
```

## Example (WRONG — will be rejected by validator)

```
ZF Cycle 1: Checked all work areas. No issues found.
ZF Cycle 2: 0 new findings. ← NO file names = NOMINAL = BLOCKING
```

## Composability

- Composes /verify-quick: run /verify-quick first, use its output as evidence in Cycle 1
- Used by /step-accept: /step-accept calls /zf-cycle internally
- Used by /proto-relay: ZF block at end of relay is generated by /zf-cycle
