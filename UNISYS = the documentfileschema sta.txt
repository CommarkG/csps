OPIA
Opus-Performed Implementation Audit. After Sonnet reports a milestone is done, Opus reads the actual commits, diffs, and file contents at the real SHA — then verifies whether Sonnet's claims are true. Returns ACCEPT (work is real, correct, complete) or COURSE-CORRECT (something is wrong — Sonnet must fix before advancing). OPIA is what prevents nominal DONE claims from slipping through.

OPIA matrix
The structured evidence table inside an OPIA block. Two columns: "Sonnet claimed X" vs "Opus verified at [file:line]." Not Opus taking Sonnet's word for it — Opus reads the disk. Every OPIA you've seen in this session has had this: a row-by-row verification of each claim against actual file contents at the actual HEAD SHA.

PREVENTION class name
A named structural failure pattern, not just a one-off bug fix. Instead of "I fixed a mistake in file X," you name the class of mistake: EXISTS-NEQ-INVOKED-AT-NERVOUS-SYSTEM, NOMINAL-PERSONA-COUNT-AT-SOURCE, MEMORY-VS-DISK-DRIFT. Naming the class means: (a) future builders can recognize and avoid it, (b) the platform can build a T1/T2/T3 enforcer for it, (c) it shows up in the gap-recurrence register. Every milestone report must name at least one.

HEAD
Git's pointer to "the current latest commit on this branch." Whatever HEAD points to is what verify.mjs runs against. When Sonnet says "verify_top_exit: 0 at HEAD b90c0826" it means: "I ran the full validator suite on the code at that specific commit, and it passed." HEAD moves forward with every new commit. Citing HEAD SHA = proof of which version was tested.

SHA
The unique 8–40 character fingerprint of a specific git commit (e.g., b90c0826). Git computes it by hashing the full contents of the commit — change anything by one byte and you get a completely different SHA. In CSPS, a SHA is the primary evidence token: "I verified this exact version, not some other version that might have changed since." You cannot alter a commit without changing its SHA, which is why OPIA cites SHAs rather than trusting "the latest version."
