## Refined Definition

**RZF — Repeated Zero Finding** is a scoped review state reached when repeated review iterations under declared scope produce **no new material findings**, while all known findings are either:

- resolved,
- accepted with explicit reasoning,
- or saved and scheduled with traceable context.

RZF does **not** mean perfection.

RZF means:

> No new material findings were discovered under the declared review scope after named re-examination, and all non-blocking future value was preserved without interrupting the current mission.

---

## Why This Matters

AI systems often declare "done" too early because they respond to completion signals:

- a polished summary,
- a checklist,
- a created file,
- user approval,
- a clean structure,
- or the feeling that the answer is good enough.

RZF is designed to prevent this.

It separates:

```text
feeling complete
from
being ready under evidence
```

It also separates:

```text
valuable future improvement
from
current-scope blocker
```

This is essential because strong systems can continue finding valuable improvements forever. If every valuable improvement interrupts the active work, the system never closes anything.

## Core RZF Principle

> Iteration is a virtue until it becomes avoidance of closure. RZF is the discipline that preserves improvement without sacrificing completion.

## Operational Logic

A proper RZF cycle should work like this:

```text
1. Declare the review scope.
2. Run an expert/persona review.
3. Classify findings:
   - current-scope material blocker,
   - material but not current-phase blocker,
   - non-material future enhancement.
4. Fix current-scope blockers now.
5. Save and schedule non-blocking findings.
6. Run named re-examination.
7. Continue only if new material blockers appear.
8. Stop when no new material findings remain under declared scope.
9. Do not claim broader completion than the scope supports.
```

## Stop Rule

The refined stop rule:

> Stop the active iteration cycle when no new material blockers remain under the declared scope, all useful non-blocking findings are saved and scheduled, and continuing would shift the system from completion discipline into improvement drift.
