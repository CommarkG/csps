# CSPS Phase 2 — Package A
## Dynamic Onboarding & Continuous Enrichment

Version: V1 | Status: Draft for External App Presentation | Maps to: PART 7

---

# Strategic Direction

Move from "ask first, help later" → **"help first, ask better later."**

The system should: start from what the user wants / avoid interrogation feeling / provide quick useful value / ask only what's relevant now / postpone non-essential questions / learn continuously / use context+files+behavior / support pause-resume / adapt without destabilizing.

# Core Principles

- **A. Continuous Onboarding** — never ends; platform keeps learning through usage, uploads, conversations, corrections, confirmations, workflow choices.
- **B. Value Before Extraction** — deliver useful value before asking deep info (quick recommendation / starter template / asset summary / dashboard preview).
- **C. Trust Before Depth** — deep questions wait until trust exists.
- **D. First Input Is Partial** — first answer is a signal, not final truth; deepen gradually.
- **E. No Interrogation** — questions feel contextual, useful, justified, connected to value.
- **F. Gentle Challenge** — help separate symptoms from root needs without confrontation.

# Suggested 5-Stage Flow Model

1. **Entry Intention** — "What are you trying to accomplish today?" (avoid long forms / sensitive questions)
2. **First Small Value** — deliver one useful modest relevant output quickly
3. **Contextual Enrichment Request** — after value: "I can make this more accurate with two quick details. 60 seconds?"
4. **Progressive Understanding** — enrich through answers, files, websites, behavior, corrections, workflow, confirmations
5. **Re-Entry & Continuation** — on return, don't restart from zero; remind what's done, offer next optional improvement

# Depth Model (4 levels)

Fundamental → Basic → Advanced → Deep Dive. Orchestrator selects depth by trust, current task, confidence, user energy, value-delivered, friction.

# Continuous Enrichment Triggers

**Good moments:** after first value / after satisfaction / after repeated workflow use / when missing detail blocks better output / after asset upload / before advanced feature activation / on re-entry.
**Bad moments:** before value / during cold start / while completing a task / right after error / after too many questions / before purpose clear.

# Delight Moments (governed)

mini strategy / checklist / template / landing page draft / marketing calendar / workflow suggestion / business summary / improved text / generated asset. **Overuse creates expectation inflation — must be governed.**

# Anti-Patterns

long initial forms / multi-page setup before value / sensitive questions too early / generic empty AI chat walls / pretending to understand before signal / too many follow-ups / 0%-pressure progress bars / forced completion before dashboard access / hiding basic features behind adaptive flows.

# Lowest-Risk Integration

1. Start onboarding with user intent. 2. Delay non-essential questions. 3. Add one quick-value output before deep collection. 4. Add "why we ask" explanations. 5. Add optional asset upload. 6. Add pause/resume state. 7. Add small profile review/correction screen.

# Final Reminder

Not a replacement order. Inspect what exists, preserve what works, suggest smallest stable improvement path.
