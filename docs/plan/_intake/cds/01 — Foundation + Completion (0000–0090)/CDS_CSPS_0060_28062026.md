# 1. What Simulation Is -- The Core Insight

In the session that produced this suite, four conceptual review passes on 32 documents found 24 structural gaps. Not one line of code was written. Every gap found at this stage costs zero to fix. Every gap that reaches code costs ten times more. Every gap that reaches production costs a hundred times more.
SIMULATION PRINCIPLE   Simulation is not testing. Testing validates behavior against expected outcomes. Simulation validates structure against declared connections. Simulation asks: does this element know where it came from? Does it know what it owes forward? Is the interface between these two elements declared and consistent? These are connectivity questions -- not content questions. Connectivity failures are invisible in code but visible in structure.
This is why connectivity and context are more important than elements. The 24 gaps found were not element failures -- every element had content. They were connection failures -- missing inheritance declarations, stale indexes, undefined authority chains, undeclared loop references. The elements were complete. The spaces between them were not.
Simulation runs on declarations -- on backpacks, schemas, and protocols -- before any code exists. It validates the conceptual model. Code then implements a model that has already been proven coherent. Implementation becomes translation, not discovery.

# 3. The Six Simulation Personas

The Simulation Agent instantiates six personas as sub-agents -- each with a different lens, each constituting one GPOW phase. Personas are maximally different from each other to ensure the simulation covers all gap type categories.
SIMULATION PRINCIPLE   Personas are not arbitrary. Each persona is optimized to detect a specific category of gap that the others are likely to miss. Together they cover the full gap detection space. The goal is not agreement between personas -- it is maximum diversity of findings.

The Simulation Agent executes as a GPOW Refinement Loop. Each persona pass is a GPOW cycle. The between-cycle protocol is the GPOW between-phase protocol from 1090.

SIMULATION PRINCIPLE   The simulation is complete when gap density reaches zero across two consecutive passes with expanded scope -- exactly as GPOW Phase 4 prescribes. A single pass with zero findings is not sufficient. The next scope expansion must also produce zero findings before the mechanism is declared proven.

BACKWARD PROPAGATION   Every connectivity gap found by simulation travels backward. If a missing forward relationship declaration is found in element 20, elements 1 through 19 are checked for the same gap. The finding is not local -- it is a pattern check. The Backward Propagation Imperative (1090) applies to simulation findings as fully as it applies to GPOW findings.
