# 1. The Canonical Definition of Corespine

The word 'corespine' appears 200+ times across 41 suite documents with subtly different nuances. This section declares the one canonical definition that supersedes all prior uses. Where prior uses align -- they are confirmed. Where they diverge -- this definition takes precedence.
CORESPINE LAW   A corespine is a governed lineage of purpose. It defines a family of related elements by answering three questions: Where does this family come from (the root)? What holds the family together (the trunk)? What are the specific expressions of the family (the branches and sub-branches)? Every element that belongs to a corespine inherits from its root, contributes to its trunk, and exists as a branch or sub-branch.

## 1.1 What a Corespine IS

Property
Definition
A lineage
A corespine traces ancestry. Every element in it knows where it came from and what it owes to the elements that depend on it.
A governing structure
A corespine is not descriptive -- it is prescriptive. Elements in a corespine behave according to the rules of their position in the lineage.
A three-layer hierarchy
Root (the origin principle), Trunk (the main sequence of the lineage), Branches and Sub-branches (specific expressions).
Inherited by pipelines
A pipeline traverses corespines. When corespines are fully ratified, pipeline construction is traversal -- not invention.
A ratification unit
A corespine must be ratified as a whole -- root, trunk, and all declared branches -- before any of its elements can be activated.

## 1.2 What a Corespine Is NOT

Not
Why This Matters
A category or tag
Categories describe. Corespines govern. An element in a category is labeled. An element in a corespine is bound.
A flowchart
A flowchart shows sequence. A corespine shows lineage. Sequence can change. Lineage does not.
A feature set
A feature set is a collection. A corespine is a family with inheritance. Features exist independently. Corespine elements depend on each other.
A static document
A corespine is a living governed structure. It evolves through ratified changes, not through edits.
Optional
An element without a corespine is floating. Floating elements are ungoverned. Ungoverned elements cannot be built, audited, or trusted.
