# 3. CS-GOV-003 -- Naming, Vocabulary & Numbering Corespine

CS-ID:  CS-GOV-003
Tags:  GOV | VOCAB | NAMING | NUMBERING | STABILITY | ANTI-DUPLICATE
Root Goal:  Govern how all elements in the platform are named, defined, and numbered -- making stability, reuse, and anti-duplication structurally enforced
Root Principle:  Every name is intentional, every definition is three-depth, every number is unique and format-declared. No name, definition, or number exists without being registered.
Layer
Elements
Rule
Root -- The Naming Obligation
Every element has a declared name. Names are stable -- they change only through ratified vocabulary updates.
Names are the handles by which AI engines reference elements. Unstable names break AI continuity.
Trunk -- Naming Format Declarations
ID formats: CS-[GROUP]-[SEQUENCE], SK-[DOMAIN]-[SEQUENCE], AG-[DOMAIN]-[SEQUENCE], PL-[NAME]-[SEQUENCE], INS-[PHASE]-[SEQUENCE], GOV-[YEAR]-[SEQUENCE]
Every element type has a declared format. No ID without a format.
Branch -- Vocabulary Standard
Three-depth definitions for every term (Core / Medium / Full). CSPS native terms vs. industry terms. Governed by 1000.
Terms without three-depth definitions are not vocabulary -- they are notes.
Branch -- Numbering System
Document numbering (0000-0140+), corespine IDs (CS-[GROUP]-[SEQUENCE]), skill IDs, agent IDs, insight IDs (IV-[CLASS]-[SEQUENCE])
No number collision across the platform. Registry ZF check before assignment.
Branch -- Anti-Duplicate Rules
ZF-REGISTRY check mandatory before any name or number assignment. Duplicate detection is automated.
The naming system is the primary defense against platform drift.
Sub-branch -- Depth-Enabling Names
Names carry depth hints: Core names are short, Medium names are descriptive, Full names are fully qualified. This enables the depth routing system to work efficiently.
Naming and depth levels are co-designed, not independent.
Sub-branch -- Bundling-Enabling Names
Names in the same corespine family share a prefix pattern. This enables the Bundling Engine to assemble related elements efficiently.
Family names enable efficient bundle assembly.
