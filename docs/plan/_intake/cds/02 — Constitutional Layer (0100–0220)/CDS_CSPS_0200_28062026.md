# 0. The Most Fundamental Principle

Nothing stands alone. Every element has a declared place, a declared connection to what it depends on, and a declared connection to what depends on it. An element without a place is an assumption. A connection without a declaration is invisible debt. The platform does not permit either.

# PREREQUISITE -- The Ratified Goal

RATIFIED GOAL -- PREREQUISITE   Nothing moves in the build without a ratified goal. A goal that has not been formally reviewed and approved by the Platform Governor is an assumption. Building on an assumption produces a system that solves the assumption -- not the need. Every false assumption at the goal level produces cascading false assumptions at every level below it.
Ratified Goal Property
Definition
What it is
A single sentence stating a felt need with an observable resolution signal
What it is NOT
A feature. A solution. A technology choice. Any of these masquerading as a goal is a solution disguised as a need.
Who approves it
Platform Governor only. Not the builder. Not the AI.
Record format
GOV-[YEAR]-GOAL-[SEQUENCE] -- decision_type = goal_ratification
Scope
Required twice: once for the overarching platform goal, and once for every pipeline built within the platform
If goal fails ratification
HELD. Governor provides specific feedback. Builder revises and resubmits.
Gate enforcement
The CDS Threshold (0220) will not open a build wizard without GOV-[YEAR]-GOAL-[SEQUENCE]. Hardwired. Cannot be bypassed.

# 3. LEG 1 -- Node Placement (Both Schemas)

LEG 1 -- NODE PLACEMENT   Before any element exists -- it has a declared position in both the Structural Schema and the Experience Schema. An element without a position in both schemas is not placed. An unplaced element cannot be wired. The chain does not start without placement.
