# 1. What the ICE Is

ICE PRINCIPLE   The Intake Classification Engine answers five questions about every input before that input enters the platform. It is not optional. It is not a recommendation. It is the mechanism that converts raw unclassified input into a governed artifact with a declared type, corespine family, tag set, status, and routing destination. Unclassified input is ungoverned input. Ungoverned input is the primary source of platform drift.
The ICE is the reason the platform can have One door. Every input -- human, AI, API, external AI response, tenant request -- passes through the same five questions. The answers differ. The questions are universal.

# 2. The Five Classification Questions

Every input is processed through these five questions in sequence. The output of Question N feeds Question N+1. No question is skipped.
