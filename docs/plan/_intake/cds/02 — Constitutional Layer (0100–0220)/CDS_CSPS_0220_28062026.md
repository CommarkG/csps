# 1. The Gate Architecture

GATE LAW   The The CDS Threshold is a standalone external interface -- not a panel inside the platform. It is the perimeter. It is the only door into the platform. This is the architectural decision that makes mechanical enforcement possible: if the gate IS the entry point, inputs cannot bypass it. A frame inside the platform is a door next to other doors. This gate is the only door.
Gate Property
Definition
Architecture
Standalone external page -- accessible at a declared URL before any platform interface
Access
Public-facing entry point. Any input source -- human, AI, API, tenant -- uses this gate.
What it runs
The ICE wizard (0210) -- five classification questions processed interactively or via structured payload
What it produces
A Classification Record (CR-[DATE]-[SEQUENCE]) and a structured artifact injected to native AI
What it enforces
Ratified goal check (no build wizard opens without GOV-[YEAR]-GOAL-[SEQUENCE]). Ratification state check (no constitutional element activated without APPROVED state). Vocabulary alignment. Platform DNA injection.
What cannot bypass it
Everything. The gate's enforcement is hardwired at the infrastructure level -- not enforced by AI discipline or human memory.

The gate handles five types of input sources. Each has its own path through the ICE wizard -- but all five produce the same output: a Classification Record and a structured artifact.

# 3. What the Gate Mechanically Enforces

GATE LAW   Mechanical enforcement means the constraint is in the mechanism -- not in the instruction. An AI that forgets the rule, a developer who tries to shortcut, a tenant who attempts to exceed scope -- none of these can succeed because the gate rejects the attempt before it completes. Enforcement does not depend on discipline.

# 5. The Gate and the Native AI -- Context Injection

The gate's most important function after classification is the context injection into the native AI session. The AI never sees raw input. The AI always starts with a structured, classified, governed context bundle.

Why First

Platform DNA prevents AI from defaulting to training patterns instead of platform patterns

The context injection is the reason the gate is a standalone page and not a frame inside the platform. The injection must happen before the platform interface opens. Once inside the platform interface, the AI is already working. The gate is where the AI is prepared.
