CORE -- Stage Backpack at Core   Stage Identity, Pipeline Position, Corespine Position, Origin, Relationship Backward (name only), Stage Goal, Wiring State, Relationship Forward (name only), Forward Obligation (name only), Failure Behavior (category only). Self-contained. No reasoning layer.
MEDIUM -- Stage Backpack at Medium   Everything in Core plus: Accumulated Inheritance (partial chain), Reasoning, detailed Relationship Backward/Forward, detailed Forward Obligation, Failure Behavior trigger conditions, three Audit Checkpoints.
FULL -- Stage Backpack at Full   Everything in Medium plus: Complete accumulated inheritance chain, complete reasoning with alternatives considered, wiring state history, full audit mirror, vault handoff declaration.

# Skill and Agent Integration -- 1010 Extension

Pipeline stages may now declare skill and agent assignments -- which skills are invoked at this stage and which agent is responsible for execution.
New Slot
Content
Depth
Skill Invocations
List of Skill IDs invoked at this stage -- from the Skill Registry (0020)
MEDIUM
Agent Reference
Agent ID responsible for executing this stage -- from the Agent Registry (0030)
MEDIUM
Authority Level at Stage
The authority level of the agent at this stage -- may differ from agent default
FULL
DYNAMIC COMPLETION   Skill and agent assignments at stage level are propagation candidates. A stage that uses a skill being improved receives the improvement through Dynamic Completion -- not through manual update.
