# Depth Extension -- Gap Type Depth Profiles

Gap Detection Protocol (1030) is extended with depth-specific detection profiles. Some gap types are fully detectable at Core depth. Others require Full depth to detect reliably.
Gap Type
Detectable at Core?
Detectable at Medium?

Why Depth Matters
Type 1 -- Orphan Stage
YES -- stage existence vs goal traceability is checkable at Core
YES -- with improved accuracy from reasoning layer
YES -- with complete audit trail of how the stage was added
Core is sufficient for basic detection. Full adds the audit trail that shows when and why the orphan appeared.
Type 2 -- Inheritance Break
PARTIAL -- can detect missing items but not their origin
YES -- partial chain sufficient for most breaks
COMPLETE -- full chain required to detect subtle breaks where an item exists but is at wrong wiring state
Inheritance breaks at Core look like missing items. At Full, breaks may be items present but stale -- only full chain reveals this.
Type 3 -- Undeclared Transition
YES -- crossing existence vs Transition Stage is binary
YES -- with inheritance translation verification
COMPLETE -- full translation declaration verification
Core detects missing Transition Stages. Full verifies the translation is correct, not just present.
Type 4 -- Unresolved Branch
YES -- branch declaration vs destination is binary
YES -- with branch criteria verification
YES -- with full audit of branch selection history
Core is sufficient for detection. Full adds verification that declared destinations are reachable.
Type 5 -- Missing Resolution Signal
YES -- resolution stage existence vs Q5 signal is checkable at Core
YES -- with signal specificity verification
COMPLETE -- verifies signal is actually produced, not just declared
Core detects missing Resolution Stage. Full verifies the signal produced matches Q5 exactly.
Type 6 -- Wiring State Mismatch
PARTIAL -- can detect obvious mismatches
YES -- with partial chain comparison
COMPLETE -- only full chain reveals subtle mismatches where intermediate items are stale
Type 6 is the gap type most dependent on depth. Core misses subtle mismatches. Full depth is strongly recommended for Type 6 detection.
