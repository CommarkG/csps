# 1. Purpose

Input:  Locked goal object from Goal Definition Wizard (2000).
Output:  A complete pipeline definition -- all stages with backpacks populated at Core depth, relationships declared in both directions, accumulated inheritance chain initialized, Gap Detection Pass 1 completed.
The Pipeline Builder Wizard translates a locked goal into a governed stage sequence. It enforces the Pipeline Protocol (1010) at every step -- preventing orphan stages, inheritance breaks, unresolved branches, and missing resolution signals before the pipeline is handed to the Corespine Mapper.

# 2. Wizard Flow

Step
Wizard Action
Gate
1 -- Load goal object
Receives locked goal from 2000. Displays Q1-Q5 for human review. Confirms goal is still accurate before building.
Human confirms goal object. Zero Findings check on existing pipelines for this goal type.
2 -- Propose stage skeleton
Wizard proposes a minimal stage sequence -- the fewest stages needed to move from entry state (Q2) to resolution signal (Q5). Presents for review.
Human approves skeleton or requests changes. Wizard never proceeds with an unapproved skeleton.
3 -- Assign stage types
For each stage -- wizard proposes the correct type (Collection / Decision / Transition / Resolution) and explains the derivation from the goal.
Human confirms each type assignment. Any disagreement triggers re-derivation before proceeding.
4 -- Declare relationships
For each stage -- wizard populates Relationship Backward and Relationship Forward slots. Shows the full relationship chain visually.
Every stage must name its predecessor and successor. Wizard blocks any stage with an undeclared relationship.
5 -- Initialize inheritance chain
Wizard populates Accumulated Inheritance slot for each stage -- starting from Q2 entry state and growing cumulatively.
Human confirms the chain at each stage. An inheritance item that seems wrong triggers review of the originating stage.
6 -- Run Gap Detection Pass 1
Wizard automatically checks Gap Types 1, 2, 4, 5. Presents all findings. Resolves or declares each as known constraint.
Pass 1 clean -- or all remaining gaps explicitly declared. No silent gaps.
7 -- Export to Corespine Mapper
Pipeline definition exported to 2020 with Pass 1 status confirmed. Vault entry created.
Human confirms export. Pipeline locked at Core depth.
The wizard never adds a stage because it seemed logical. Every proposed stage is traced to the goal object before it is shown to the human. If the wizard cannot trace a stage to Q1 or Q5, it does not propose it.
ZERO FINDINGS MANDATORY   Step 2 -- before proposing a skeleton -- check the Pipeline Registry for existing pipelines serving a similar goal. An existing validated pipeline may be the starting point, not a blank build.
DYNAMIC COMPLETION   Every completed pipeline is a vault entry. Recurring pipeline patterns -- stage sequences that appear across multiple goal types -- are flagged for abstraction into reusable pipeline templates.
