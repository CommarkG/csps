# 1. Purpose

Input:  Validated pipeline from Pipeline Builder Wizard (2010) -- Pass 1 clean.
Output:  Complete Corespine Map -- all corespines declared, all crossings identified, Transition Stages inserted, Gap Detection Pass 2 completed.
The Corespine Mapper Wizard makes the invisible visible. Every pipeline crosses corespine boundaries -- but those crossings are invisible at the stage level. This wizard surfaces them, names them, inserts Transition Stages, and produces the Corespine Map that governs every downstream decision.

# 2. Wizard Flow

Step
Wizard Action
Gate
1 -- Load pipeline
Receives validated pipeline from 2010. Displays all stages with types and relationships. Confirms Pipeline Q3 corespine declarations.
Human confirms corespine list from Q3 is complete before mapping begins.
2 -- Build lineage tree
For each declared corespine -- wizard builds the three-layer structure (Root, Trunk, Branches). Populates Root Declaration from pipeline goal.
Human confirms each corespine's Root Declaration traces back to pipeline Q1.
3 -- Assign stages to corespines
Each pipeline stage is assigned its corespine position. Wizard flags stages that cross corespine boundaries.
Every stage has a declared corespine position. No floating stages.
4 -- Identify crossings
Wizard identifies every point where the pipeline moves between corespines. Presents crossing list for review.
Human confirms crossing list is complete. Any missing crossing is declared or the pipeline is updated.
5 -- Insert Transition Stages
For each crossing -- wizard inserts a Pipeline Transition Stage with a full backpack. Populates Inheritance Translation fields.
Human confirms each Transition Stage's Inheritance Translation -- what transfers, transforms, terminates, is new.
6 -- Run Gap Detection Pass 2
Wizard checks Gap Type 3 and re-checks Type 2 for any new breaks created by corespine mapping.
Pass 2 clean -- or all gaps declared. Corespine Map locked.
7 -- Export to Gap Detection Engine
Corespine Map exported to 2030. Vault entry created.
Human confirms export.
A corespine crossing that is not in the wizard's crossing list is a Gap Type 3. The wizard does not let the human proceed past Step 4 with an incomplete crossing list -- not even with one missing crossing.
DYNAMIC COMPLETION   Every Corespine Map is a vault entry. Recurring corespine patterns -- lineages that appear across multiple pipelines -- are flagged for abstraction into reusable corespine templates.
