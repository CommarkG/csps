# 1. Purpose

Input:  Gap-clean pipeline and corespine map. Pass 3 gate open.
Output:  Complete Page Map -- every stage assigned to a page, all page backpacks populated at Core depth, all page-to-page handoffs declared, responsive variants noted.
The Page Distributor Wizard translates the abstract pipeline into navigable pages. It enforces the Page Distribution Protocol (1040) -- ensuring every assignment decision passes the four distribution questions, every page boundary has a declared handoff, and every page type is drawn from the validated registry.

# 2. Wizard Flow

Step
Wizard Action
Gate
1 -- Zero Findings on templates
Check Template Registry (from 1060) for existing page templates matching the page types needed. Present matches for review.
Human confirms which templates exist and can be used before any new template is proposed.
2 -- Propose page groupings
Wizard groups pipeline stages by logical micro-goal and corespine membership. Presents proposed pages for review.
Human approves groupings or requests splits/merges. Four distribution questions applied to each grouping.
3 -- Assign page types
Each proposed page is matched to a page type from the validated registry. New types require justification.
All page types declared. No untyped pages.
4 -- Declare page sequence
Wizard proposes the user's path through the pages. Presents as a sequence with reasoning for each adjacency.
Human confirms sequence. Any reordering triggers re-check of the four distribution questions.
5 -- Populate page backpacks
For each page -- wizard populates all Core-depth backpack slots including Entry State and Relationship Backward/Forward.
All Core slots populated. Human reviews Entry State declarations for accuracy.
6 -- Declare handoffs
For each page boundary -- wizard produces the page-to-page handoff declaration. Human reviews each handoff.
Every handoff declares what passes, what is consumed, and the receiving entry state.
7 -- Responsive variants
For each page -- wizard notes responsive behavior at desktop, tablet, mobile. Flags any primary action that would be below fold on mobile.
All mobile CTAs confirmed above fold. Any violation flagged for resolution.
8 -- Export Page Map
Complete Page Map exported to Element Configurator (2050). Vault entry created.
Human confirms export.
ZERO FINDINGS MANDATORY   Step 1 is non-negotiable. Template reuse is the mechanism that makes the platform consistent. A wizard that skips the template check and creates new pages from scratch is destroying the compounding value of every previous template definition.
DYNAMIC COMPLETION   Every new page type created by this wizard is a vault entry. Page type innovations propagate to all future pipelines where that page type would be applicable.
