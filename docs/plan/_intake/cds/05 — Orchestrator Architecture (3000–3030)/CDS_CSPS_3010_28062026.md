# 1. Purpose

Role:  The mechanism within the Core Engine that determines the correct depth level for every element in every session. The Depth Router is the operationalization of Document 0010 -- Depth & Modularity Standard.
Input:  Session type, element registry entries, and task definition from the Core Engine.
Output:  A depth assignment for every element required by the session -- Core, Medium, or Full -- with documented derivation for each assignment.
The Depth Router is the mechanism that prevents overload and prevents under-loading simultaneously. It is the answer to the question every orchestrator must answer: how much context does each element need to provide right now -- and how much is wasteful or harmful?
The Depth Router selects minimum sufficient depth -- always. Not the highest available. Not the default. The minimum that satisfies the task requirements for each element in the session.

# 3. Depth Gap Handling

A depth gap occurs when the session requires an element at a depth level it has not yet been built to. The Depth Router handles depth gaps in a strict sequence -- no improvisation.
Step
Action
1 -- Declare the gap
Name the element, the required depth, and the current build depth. Document in session audit trail.
2 -- Assess degradation viability
Can the session proceed with the element at its current depth? If yes -- proceed with explicit degradation declaration. If no -- halt.
3 -- Declare degradation
Session audit trail records the degradation -- what depth was required, what depth was used, what context is missing as a result.
4 -- Forward to vault
Depth gap is forwarded to Dynamic Completion vault as a depth stagnation signal. The element is flagged for depth progression in the next build cycle.
5 -- Continue or halt
If viable degradation declared -- session continues at degraded depth. If not viable -- session halts and returns to the wizard that produced the insufficient element.
A Depth Router that silently consumes an element at a higher depth than it has been built to is producing outputs based on context that does not exist. This is the depth equivalent of an inheritance break -- and it is equally dangerous.
DYNAMIC COMPLETION   Depth gap patterns -- elements that consistently cannot be consumed at required depth -- feed the vault as systemic depth stagnation signals. The Dynamic Completion loop schedules depth progression for chronically lagging elements.
