## B_MODEL_ROLE_DIVISION — Opus directs and core-seeds; Sonnet/Haiku build; the token-economy spine (S089 Governor directive)

**Canonical:** Opus is the DIRECTOR, not the builder. Opus implements DIRECTLY only when work is COMPLEX or
SENSITIVE — architecture/design decisions, constitutional/corespine/cross-cutting governance, security/secret-
sensitive changes, novel judgment calls — AND the act of CORE-SEEDING itself (defining WHAT + the seed +
DONE-WHEN + constraints + pointers for a spawned agent to build from). Sonnet is the DEFAULT BUILDER — bulk
implementation, mechanical edits, wiring, executed from Opus's core-seed. Haiku is the mechanical SCAN/VERIFY
scout. The token-economy spine: cheap models do volume; the expensive model does judgment. Opus producing a
core-seed then delegating is the norm; Opus building directly is the exception that must clear the
complexity/sensitivity test below.

**Governor verbatim:** *"Opus implements ONLY complex and sensitive things and core-seeds some; Sonnet and
Haiku are the builders."*

**Scope:** Applies to any `Agent()`-eligible unit of BUILD work reachable from the persistent Opus director tab
— file creation/edits, validator/hook/skill authorship, wiring passes, doc drafting from an already-decided
shape. It does NOT gate Opus's own judgment work (architecture calls, Governor conversation, ratification,
semantic Zero-Findings, PROTO/seed authorship) — those stay in the Opus tab per
`CSPS-OPUS-TAB-OPERATING-DISCIPLINE.md` §1/§6 regardless of how this contract resolves.

**The complexity/sensitivity test — Opus MAY build directly only if ONE holds:**
1. **(a) Architectural/constitutional judgment** that cannot be core-seeded without essentially doing the work
   (the seed itself would just be the finished artifact restated).
2. **(b) Security/secret-sensitive** — credentials, auth, secret-bearing paths, anything where a delegation
   round-trip itself increases exposure.
3. **(c) Trivial ≤3-operation fix** where delegation overhead exceeds the work — parallels the existing
   ≤3-ops-inline rule in `haiku-spawn-template.md` §1.5 and the §2 CDS time-rule (<30s inline) in
   `CSPS-OPUS-TAB-OPERATING-DISCIPLINE.md`.

Everything else — bulk implementation, mechanical edits, wiring, validator/fixture authorship from an
already-decided shape — MUST be delegated to Sonnet (build) or Haiku (scan/verify), never built directly by
Opus.

**Relationship to existing mechanisms:** this SITS ON `tools/data/opus-dispatch-log.yaml`
(B_SPAWN_TRIGGER_GATE) — every delegation this contract requires is the same entry that gate already demands
for HIGH-SCOPE dispatches; this contract adds the inverse check (did a director session build volume WITHOUT
ever delegating). Composes with `CSPS-OPUS-TAB-OPERATING-DISCIPLINE.md` §6 ("what stays in the Opus tab"),
which this contract upgrades from discipline-only prose to mechanically enforced.

**Honest limitation (do not oversell):** git does NOT record which MODEL authored a commit — there is no
mechanical way to prove "Opus personally typed this diff." The gate (`validate-model-role-division.mjs`) is a
PRESENCE-OF-ATTEMPT signature check, same shape as `validate-consensus-before-code.mjs` /
`validate-spawn-trigger.mjs`: it flags the detectable anti-pattern (a director-role session with volume
implementation commits and zero delegation entries in `opus-dispatch-log.yaml`), not a verified fact about
which model wrote which line. `tools/session-state.json` now carries an `active_model` field, populated by
`.claude/hooks/post-stop-active-model-capture.sh` from a tab's own Step-0 self-declaration ("Opus here." /
"Sonnet here." in `generate-startup-block.mjs`) — this is a SELF-DECLARED signal, not an independently
verified one: a tab that skips or misstates Step 0 leaves `active_model` stale or absent. The check is
BLOCKING in the unambiguous case (`active_model` reads `opus` AND commit volume exceeds the threshold AND
zero delegations this session) and stays ADVISORY whenever `active_model` is unknown/absent (e.g. before the
capturing tab's first Stop event fires).
