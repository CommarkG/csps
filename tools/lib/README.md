# tools/lib/ — Canonical Shared Library

> **AMENDMENT-1 (S086):** This directory is the SSoT for shared hook utilities.
> Before hand-rolling any inline implementation in a hook or validator, check here first.
> If a function exists here, SOURCE IT — do not copy-paste or reimplement.

## Libraries

### `hook-read-prompt.sh`

**Purpose:** Canonical 3-source prompt reader for all `user-prompt-submit-*.sh` hooks.

**Contract:**
- Source 1: STDIN JSON field `.prompt` (Claude Code primary — hooks receive `{"prompt":"..."}` on stdin)
- Source 2: `$CLAUDE_USER_PROMPT` env var (fallback — not set by Claude Code as of S086)
- Source 3: `$1` positional arg (fallback for manual invocation)

**Usage in a hook:**
```bash
PROMPT="$("$REPO_ROOT/tools/lib/hook-read-prompt.sh")"
```

**Why mandatory:** Claude Code does NOT set `$CLAUDE_USER_PROMPT`. Before AMENDMENT-1, hooks that used `CLAUDE_USER_PROMPT` as primary read empty strings — silent failure causing 842/845 threshold entries to have empty previews.

**BLOCKING backstop:** `tools/validators/validate-hook-prompt-source.mjs` v2.0.0 — FAILS if any `user-prompt-submit-*.sh` hook reads the prompt but does NOT source this file.

### `emit-governed-md.mjs`

**Purpose:** Canonical creator of CSPS-governed `.md` files with full YAML frontmatter. Replaces all inline `echo`/`cat > file << HEADER` patterns in hooks.

**Contract:** Takes env vars as input, writes a fully-formed governed `.md` file:

```bash
EMIT_PATH="/path/to/output.md"   \
EMIT_ID="csps.handoff.vault.xxx" \
EMIT_NAME="my-file"              \
EMIT_DESCRIPTION="What this is"  \
EMIT_SESSION="S086"              \
EMIT_HEADER="My File — S086"     \
EMIT_COMMENT="auto-generated by hook-name.sh" \
node "$REPO_ROOT/tools/lib/emit-governed-md.mjs"
```

Optional env vars (defaults shown): `EMIT_TYPE=reference`, `EMIT_LIFECYCLE=production`, `EMIT_LIFECYCLE_STATE=active`, `EMIT_CORE_SPINE=GVRN`, `EMIT_SCHEMA_ANCHOR=vault_files`, `EMIT_IMPL_STATUS=active`, `EMIT_VERSION=1.0`, `EMIT_OWNER=group:finky`.

**Usage from a hook (create-once pattern):**
```bash
if [[ ! -f "${OUTPUT_FILE}" ]]; then
  EMIT_PATH="${OUTPUT_FILE}" \
  EMIT_ID="csps.handoff.vault.my-section.${SESSION_ID}" \
  EMIT_NAME="my-section-${SESSION_ID}" \
  EMIT_DESCRIPTION="Auto-generated log for ${SESSION_ID}" \
  EMIT_SESSION="${SESSION_ID}" \
  EMIT_HEADER="My Section — ${SESSION_ID}" \
  EMIT_COMMENT="auto-generated by my-hook.sh" \
  node "$REPO_ROOT/tools/lib/emit-governed-md.mjs" 2>/dev/null || true
fi
```

**Windows note:** CLI mode detection uses `fileURLToPath(import.meta.url)` + `resolve()` comparison (NOT `import.meta.url === \`file://${process.argv[1]}\`` which fails on Windows due to path separator mismatch).

## AMENDMENT-1 Mandate (ratified S086, Opus #25)

1. **All** `user-prompt-submit-*.sh` hooks that read the user prompt MUST call `hook-read-prompt.sh`
2. **All** hooks that create governed `.md` files MUST use `emit-governed-md.mjs`
3. `tools/lib/` is the canonical library — never hand-roll inline equivalents

Enforcement:
- `validate-hook-prompt-source.mjs` v2.0.0 — BLOCKING if hook reads prompt but doesn't source canonical reader
- Pre-commit hook (D-fold, pending): validator mtime > audit-runner.md mtime → BLOCKING

## Prevention class: CANONICAL-LIBRARY-DRIFT

Root cause prevented: 6 hooks each had their own STDIN reader → 1 had a bug (CLAUDE_USER_PROMPT fallback only) → 842 empty threshold entries. Single canonical reader makes this un-authorable.
