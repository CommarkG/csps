## New Finding 1: ADHD User Profile

The document explicitly mentions "executive-function deficits (such as ADHD profiles)" as a primary user type this system is designed for.

**CSPS implication:**
- ADHD is a specific Human Psychology Hub user sub-profile
- Behavioral differences from neurotypical users:
  - Higher cognitive load sensitivity (V1 Sponge is strongly preferred)
  - Lower tolerance for V2 Auditor diagnostics (can feel overwhelming)
  - Stronger response to the "mental dump release" value proposition
  - Different notification calibration (lower urgency threshold to start, or batched/quiet)
- APP-001 Alex profile: "cognitive-offload professional" — ADHD may be explicitly in scope
- B_HUMBLE_FIRST_STEP applies: don't ask about ADHD. Observe and calibrate based on usage patterns.

## New Finding 2: Construction Chunking Canonical Example

The raw voice input and the three-chunk breakdown is the best explanation of the Threshold/ingestion system in any document:

```
Raw voice: "Hey, we are running behind on foundation layout, tell concrete dispatch to
hold the trucks, also remember buy milk on the way home, and make sure we don't pay 
the masonry bill until I check their license status."

Chunk 001 [Business/Logistics]:  Delay event → project foundation timeline
Chunk 002 [Private/Personal]:    Shopping → private silo (excluded from business log)
Chunk 003 [Business/Risk]:       Financial hold → masonry + compliance dependency
```

**What makes this the killer feature:** The system separated private from business data INSIDE a single voice input, without the user doing anything, without them labeling anything, without them pausing and thinking "wait, that personal bit should go elsewhere."

This example should be CSPS's canonical explanation of how the ingestion pipeline works.
